# research.md · T036 都江堰的第一股江水（第25夜 · 2026-09-15）

> 选题：约前 256 年，李冰主持的都江堰完工放水——斩杩槎，岷江水头涌入内江，水线爬上宝瓶口的凿痕石壁。

## 事实清单（A 史料确认 / B 合理推断 / C 艺术创作）

1. **A · 工程本体**：《史记·河渠书》「蜀守冰凿离碓，辟沫水之害」——李冰（秦蜀守）主持凿离堆、开宝瓶口，都江堰约前 256 年建成；鱼嘴分水、飞沙堰、宝瓶口三大件沿革有据。
2. **A · 杩槎截流**：都江堰岁修以杩槎挡水断流——三根长木绑扎的三脚架，内填竹笼卵石；清明「砍杩槎」放水仪式延续至今（仪式成制为清代，作为工程动作的「拆杩槎放水」B 级合理）。
3. **B · 放水水势**：岷江春汛水量下，杩槎一开、水头涌入内江，数分钟内水线沿开凿石壁爬升——物理合理推断 B。
4. **B · 李冰形象**：中年秦国官员，细麻深衣、束发戴帻、短须；无实像传世（后世庙塑为老年持卷，不取）。B 级推断。
5. **B · 宝瓶口石壁**：人工凿痕离堆红砂岩，凿痕与水痕经年累月可见——「水线爬过凿痕」的视觉锚 B 级。
6. **C · 当刻李冰的静观与斫官动作**：艺术创作。

## L-009 / Rule-507 风险与回避（指名要什么 + 否定式条款）

- **风险一（现代景区先验）**：「都江堰」极易出安澜索桥、二王庙、游客、栏杆——否定式：**无桥梁、无庙宇、无栏杆、无游客、无任何现代元素**；工地只由土岸、红砂岩石壁、杩槎阵、竹笼构成。
- **风险二（杩槎认形）**：三脚架易被渲染成抽象装置——指名：**三根碗口粗长木顶端绑扎成人字三脚架，迎水面堆竹笼卵石**，数量三至五架成列。
- **风险三（李冰戏曲化）**：影视/戏曲李冰=白髯老者——指名：**四十多岁、短须、细麻深衣、布帻**（Rule-507 特征清单）。
- **Rule-508 应用**：转折=水头涌入、水线漫过石壁凿痕——物质现象静帧可验证；不依赖人物表情或帧间微动作。
- 工具否定式（T021 矛尖教训）：斧为素铁斧无纹饰；**无任何金属机械、滑轮、绳索起重机**。
