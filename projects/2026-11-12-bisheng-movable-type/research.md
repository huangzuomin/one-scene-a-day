# 研究 · T009 毕昇把胶泥活字送入窑火

## 事实清单（A 史料确认 / B 合理推断 / C 艺术创作）

### A · 史料确认
- 沈括《梦溪笔谈·技艺》记载：庆历年间（1041–1048），布衣毕昇发明活字印刷术——"用胶泥刻字，薄如钱唇，每字为一印，火烧令坚。"
- 排版工艺（沈括原文）：以铁板为底，布字印于其上，"松脂、蜡和纸灰之类冒之"；"欲印，则以一铁范置铁板上，乃密布字印，满铁范为一板，持就火炀之，药稍镕，则以一平板按其面，则字平如砥"。
- 常作二铁板轮换："一板印刷，一板布字，此印者才毕，则第二板已具。"
- 毕昇身份为"布衣"（平民匠人），非官员；活字为胶泥烧制，区别于后世木活字、铜活字。
- 活字字形为反刻（印章式反字），印出方为正字。

### B · 合理推断
- 烧制场景：胶泥活字须入窑火烧硬；宋代制陶多用馒头窑/土窑，窑口拱顶低矮、火光自窑膛透出，窑坊夜间作业以火光为唯一暖光源。
- 毕昇年龄不详，本片设定四十岁上下匠人（Rule-503 年龄锚点）；服饰为北宋平民交领短衫、布巾包头、粗布深青色。
- 取字工具为竹夹/木夹（夹取未烧制的胶泥字，防指纹损字）；工作台为木案，案上置铁板、陶钵（松脂蜡）、未烧活字。
- 庆历年间为北宋仁宗朝，汴京为都城；窑坊设于城郊（本片不指名具体窑址，画面只呈现窑坊内部）。

### C · 艺术创作
- "字墙"构图：本片把排满胶泥活字的铁板集中呈现为一面竖立的字墙，火光漫过时整面亮起——实际活字平铺于铁板上，竖墙为视觉转折的艺术集中，非史实形制。
- "最后一枚活字入窑"的具体夜晚无史料记载，为虚构的核心瞬间；窑火腾起的节奏、毕昇的屏息停顿均为戏剧化处理。

## 关键视觉元素（须达 B 以上）
- 胶泥活字：灰褐陶土色，方块小印，字形为模糊反刻纹理，不可辨认（Rule-505 文字载体自检）。
- 窑：宋代土窑，矮圆拱顶窑口，窑膛内橙红火光；不用现代砖窑/烟囱。
- 铁板与木案：深色铁板、原木案面、陶钵。
- 服饰：北宋平民交领短衫（深青/灰褐），布巾包头；不用明清立领、马褂、现代工装。

## Rule-505 第二层图案自检（四类高频泄漏位）
1. 墙线/文字载体：活字字形必须模糊如印章纹理，画面中不出现任何可读正字汉字；字墙是反字阵列，不是字帖。
2. 柱式/建筑：窑坊为土坯矮墙+木梁，不用砖石长城式墙体、不用宫殿斗拱。
3. 人群排布：单主角，不出现作坊人群/军列化排布。
4. 光线：单一暖光源=窑火；封堵环境补光位（门缝、窗洞不另设暖光），冷暗窑坊大底只衬窑火。

## Rule-507 指名防御
- 关键器物给独有特征清单：胶泥活字=灰褐陶土、方块、反刻模糊字纹、不是木活字、不是金属字模；窑=矮圆拱顶土窑、窑口一人高、不是高烟囱砖窑。
