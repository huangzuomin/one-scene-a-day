# 脚本 · 黄道婆的三线齐张

## 节奏诊断（R-105）
类型能量：安静观察 / 情绪领悟 / 观众感受速度：慢，清晨纺织屋的呼吸感 /
目标总时长：15s / 平均 Beat 时长：约 3.75s / 最快 Beat：收束 hold 3s /
最慢 Beat：建立/起摇各 4s / 必需停顿：起摇前屏息 0.5s；三线齐张后凝视 1s /
收尾停留：3s（三线亮线 + 油灯暖光 + 纺车剪影）

## 15 秒微故事（2 镜头组，一次转折）
清晨，松江乌泥泾的一间纺织屋。木梁土墙，木窗棂在左，晨光还没落进来；
木质三锭纺车居中，桌上放着一盏油灯，棉絮与轧车只作背景静置。
一位五十岁上下的农妇站在纺车前——深蓝粗布对襟短衫、素色长裙、头巾包发、
腰系围裙、右手扶着纺车摇柄。
她屏息半秒，手摇摇柄：第一枚锭子转动，一根棉纱缓缓绷直。

摇柄再转半圈，第二枚、第三枚锭子同时转动——
三根棉纱齐齐绷直，成三道亮线横贯画面，晨光正落在纱线上。
她停住，低首凝视着三道亮线，一秒。

她手扶摇柄，不再摇动。画面在三线亮线、纺车与她的剪影上静静 hold 住，
屋里只有一盏油灯的光和三根刚刚绷直的线。

## 声音暗示（R-305）
- 纺织屋清晨的寂静与窗外极远的鸡鸣（全片底噪）
- 她屏息扶柄时一切声音收住（0–4s，一顿）
- 起摇时纺车木轴极轻的吱呀一声（4–8s，声音的起）
- 三线齐张的刹那，纱线绷直的轻响，随后全静（转折点的静）
- 结尾：摇柄停稳的一声轻响，油灯声回归
