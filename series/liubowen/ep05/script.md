# EP05 论相与谈洋 · 15秒脚本

## 节奏诊断（R-105 八字段）

| 字段 | 值 |
|---|---|
| 类型能量 | 安静观察 → 忧谗顿挫（沉降型） |
| 观众感受速度 | 极缓；唯一的响动在黑子拍落 |
| 目标总时长 | 15 秒 |
| 平均 Beat 时长 | 3.75s |
| 最快 Beat | 3s（黑子落枰特写） |
| 最慢 Beat | 4.5s（对坐全景） |

| 收尾停留时长 | ≥2s |

## 故事（一句话）

冬夜便殿棋室，君臣对坐一局残棋——帝手拈黑子悬停，重重拍落枰心：用胡惟庸，帝意已决。刘伯温凝视那枚黑子，缓缓摇头，抬手欲谏、半途停住，终于垂手，抬眼望向对面的背影。

## 脚本（3 个镜头组 · 4 Beats · 一次转折）

**镜头组一｜全景（0–4.5s）**
冬夜棋室，一局残棋未收。君臣对坐棋枰两侧：右侧朱元璋背对镜头（玄袍玉带，翼善冠），左侧刘伯温正面偏侧。宫烛与炭盆是仅有的暖光。帝的手探入棋罐，拈出一枚黑子，悬在枰上——悬停半拍。

**镜头组二｜特写（4.5–7.5s）——转折**
枰面特写：黑子重重拍落在枰心——棋子轻跳，烛焰猛地一晃。帝意已决。

**镜头组三｜中近景（7.5–11s）——欲谏还休**
刘伯温凝视那枚黑子，缓缓摇头；右手抬起半途——停住（「譬之驾，惧其偾辕也」在喉）——终于垂手。

**镜头组四｜中近景（11–15s）——定格**
他垂眸，再抬眼望向对面的背影，烛光切过半张脸。棋枰上黑子压在枰心，白子散落如孤臣。最后两秒构图完全静止，hold 到结束。

## 声音暗示（R-305，本集起实际生成环境音）

更漏滴水、炭盆噼啪、宫外隐约更鼓 → 棋罐里棋子的轻响 → **黑子拍落枰心的一声脆响 + 烛焰一晃**（全片声音重音，剪辑点）→ 骤静里只剩更漏 → 衣袍摩擦的细微声收尾。不要旁白与对白。

## 转折设计（R-302 自检）

本集转折的主角是**另一只手**：帝意拍落黑子，他的预言被无视——这不是他做决定，而是命运替他做了决定。因果链：问相（悬停）→ 用惟庸（拍落）→ 谏不可得（欲言又止）→ 祸根种下（对视定格）。低强度、强因果：✓。声音重音（落子脆响）替代光变成为转折载体，与 EP1–4 的光效系列互补。
