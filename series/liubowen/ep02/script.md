# EP02 出山择主 · 15秒脚本

## 节奏诊断（R-105 八字段）

| 字段 | 值 |
|---|---|
| 类型能量 | 安静观察 → 决然启程（沉降转昂扬） |
| 观众感受速度 | 极缓；唯一光变在推门一瞬 |
| 目标总时长 | 15 秒 |
| 平均 Beat 时长 | 3.75s |
| 最快 Beat | 3s（星图最后一眼） |
| 最慢 Beat | 4.5s（结尾逆光定格） |
| 必需停顿 | 星图凝视时一次呼吸停顿；推门后满室光转的一静 |
| 收尾停留时长 | ≥2s |

## 故事（一句话）

1360 年春黎明，青田书斋——他把卷好的星图最后凝视一眼、放进书箧，提箧推门，晨光涌入：隐士生活合上了，帝业之途打开了。

## 脚本（3 个镜头组 · 4 Beats · 一次转折）

**镜头组一｜全景（0–4.5s）**
黎明前最暗的书斋，案头烛将尽。案上摊着孙炎的聘书，旁边是卷好的星图，案角一摞《郁离子》书稿。他立在案前，看着这一切——两年隐居收拾进一只书箧。

**镜头组二｜特写（4.5–7.5s）——「星图最后一眼」**
他的双手拿起星图卷轴，缓缓展开一尺：墨线星官、朱砂星点在烛光里微亮。他垂首凝视，一动不动，一次呼吸的停顿——观了半生的天，看最后一眼。

**镜头组三｜中近景（7.5–10.5s）**
他把星图轻轻放入敞口书箧，俯身提起书箧，直起身。烛火在他身侧晃了一下。

**镜头组四｜中景（10.5–15s）——转折与收束**
他伸手推门。门开一瞬，冷青晨光自门外涌入压过烛光，室内光线反转，山间晨雾与远山在门外展开。他提箧立于门框内，成为逆光剪影，肩线平静。最后两秒构图完全静止，hold 到结束。

## 声音暗示（R-305）

黎明前最深的静（烛芯将尽的噼啪）→ 卷轴展开的纸声 → 木箧提起的重量感 → **门轴一声 + 晨鸟与山风涌入**（全片唯一重音，剪辑点所在）→ 静里带一点点天亮的生气。

## 转折设计（R-302 自检）

EP01 的转折是「最亮一瞬的爆」（灯花），EP02 的转折是「光的世界的打开」（门开晨光涌入）——同一动作量级（一次推门 vs 一次合盖），方向相反：合上 vs 打开。因果链——聘书已至（孙炎固邀）→ 星图收箧（收山）→ 门开晨光（入世）。低强度、强因果：✓。

## 铁律自检

一个瞬间（出山前的黎明）✓｜一条动作线（星图入箧、提箧出门，止于门槛内）✓｜一种情绪（慨然）✓｜单主角（仅一人）✓｜单空间（书斋，门外为门框内的亮底）✓｜一次视觉转折（门开光转）✓

## EP01 教训修正项

① 长髯长度白度与参考图一致、全程不变；② 全程站立不坐；③ 结尾光线写死（晨光逆光勾边）。
