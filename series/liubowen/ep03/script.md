# EP03 鄱阳湖换船 · 15秒脚本

## 节奏诊断（R-105 八字段）

| 字段 | 值 |
|---|---|
| 类型能量 | 动作（战场）→ 神定收束（系列签名静） |
| 观众感受速度 | 前段急（钩子+救主），后段骤静（爆炸后的耳鸣式静） |
| 目标总时长 | 15 秒 |
| 平均 Beat 时长 | 3.75s |
| 最快 Beat | 3s（俯瞰战场钩子） |
| 最慢 Beat | 4.5s（水柱回眸定格） |
| 必需停顿 | 跃起前半拍凝视；巨响后一瞬骤静 |
| 收尾停留时长 | ≥2s |

## 故事（一句话）

1363 年鄱阳湖，炮战正烈——刘伯温看见的比别人早一步：他跃起大呼，把朱元璋从胡床上曳起、登上紧邻小舸；两人离开的一瞬，飞炮击碎旧舰，水柱冲天，而他的侧脸在水雾里静定如常。

## 脚本（3 个镜头组 · 4 Beats · 一次转折）

**镜头组一｜俯瞰（0–3s）——战场钩子**
大远景俯瞰：陈友谅的丹漆楼船联成巨阵，朱元璋的轻舟在其间穿梭，远处黑烟腾起，旗幡翻卷（只有颜色图案，没有文字）。一颗石弹划过弧线坠入近处水面，白色水柱炸起，水雾漫开，过渡到甲板。

**镜头组二｜甲板中景（3–6.5s）——先见之明**
画面右侧，朱元璋背对镜头坐在胡床上督战（绛红袍巾）；画面左侧，刘伯温侍立。他的目光骤然锁定画面右后方来路的水面——他看见的比别人早一步。半拍凝视之后，他跃起、一声急呼。这是全片唯一的动作加速。

**镜头组三｜跟随（6.5–10.5s）——救主**
他一把攥住朱元璋的手臂，将他从胡床上曳起，快步两步向画面左侧舷边；朱元璋跨上紧邻的小舸。跨步落定的同时，刘伯温回头——目光投向右后方刚才的坐舰。

**镜头组四｜小舸回望（10.5–15s）——转折与签名帧**
飞炮击中旧舰：白光一闪，水柱裹着碎木冲天（画面右后方，全片只此一次），水雾向镜头漫来。前景左侧是刘伯温回望的侧脸，神情静定如常，水光在他脸上明明灭灭。水柱缓缓回落，碎屑纷落。最后两秒构图完全静止，hold 到结束。

## 声音暗示（R-305）

战鼓与喊杀压底 → 石弹破空尖啸、水柱炸响 → 他的一声急呼 → 跨舸脚步与木板闷响 → **巨响之后一瞬的骤静（耳鸣式）** → 水柱落下的哗响收尾。骤静是情绪剪辑点。

## 转折设计（R-302 自检）

本集是系列唯一例外：转折不是低强度动作，而是「飞炮碎舰」——但因果链同样成立且为史料原文（跃起呼更舟 → 仓卒徙坐 → 飞炮立碎）。转折落成静帧可验证的画面（水柱冲天），不押注帧间微动作（Rule-502）。人物动作本体保持克制：曳行两步、跨舸一次、回眸一顾（R-304）。

## 铁律自检

一个瞬间（换船）✓｜一条动作线（曳行登舸）✓｜一种情绪（神定）✓｜清晰人物两位（≤3）✓｜单空间（一条船的甲板+紧邻小舷）✓｜一次视觉转折（旧舰碎，只出现一次）✓

## 系列对仗

EP1 决绝（封存）→ EP2 慨然（开启）→ EP3 神定（先见）。三集情绪递进，静—动—静的系列节奏在本集达到唯一的"动"。
