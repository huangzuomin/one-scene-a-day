# EP06 病榻献书 · 15秒脚本

## 节奏诊断（R-105 八字段）

| 字段 | 值 |
|---|---|
| 类型能量 | 安静观察 → 释然收束（系列最缓一集） |
| 观众感受速度 | 极缓近乎凝滞；唯一的响动是松手时的灯花轻爆 |
| 目标总时长 | 15 秒 |
| 平均 Beat 时长 | 3.75s |
| 最快 Beat | 3s（抚卷特写） |
| 最慢 Beat | 4.5s（开场全景与结尾定格） |
| 必需停顿 | 抚卷时一次悠长的呼吸；松手后满室一静 |
| 收尾停留时长 | ≥2s |

## 故事（一句话）

1375 年春夜，青田故宅，病榻上的刘伯温把毕生《天文书》卷轴交到长子手中——手指一根根松开，灯花轻爆一声；他望着手稿离去的方向，眼神澄定如释。

## 脚本（3 个镜头组 · 4 Beats · 一次转折）

**镜头组一｜全景（0–4.5s）**
春夜微雨的老宅卧房，一盏油灯。他半卧病榻，病中清减、气息微弱但神志清明；长子跪坐榻边背影。榻前小案上放着一函卷轴，窗下案角一只空药碗微微虚化。窗外雨声若有若无。

**镜头组二｜特写（4.5–7.5s）——抚卷**
他的枯瘦的手从被中缓缓伸出，指腹搭上卷轴，轻轻抚过——像最后一次核对星图。一次悠长的呼吸。

**镜头组三｜特写→中近（7.5–11s）——递交·松手·转折**
长子双手接过卷轴——卷轴在两双手之间易主，他的手指一根根松开；就在松开的一瞬，油灯灯花轻爆一声（与 EP1 的灯花爆亮遥相呼应）。满室一静。

**镜头组四｜中近景（11–15s）——收手·定格**
他把空了的手缓缓收回被上，抬眼望着手稿离去的方向——长子捧卷轴的侧影在画面右缘微微低头。油灯暖光切过他的半张脸，眼神澄定如释。最后两秒构图完全静止，hold 到结束。

## 声音暗示（R-305，环境音实际生成）

深夜极静：春雨落在瓦檐上若有若无、更漏、烛芯偶尔轻爆 → 被褥与衣袍的窸窣 → 纸卷离手的窸窣声 → **松手一瞬灯花轻爆的一声**（全片声音重音）→ 只剩雨声与更漏。不要旁白与对白。

## 转折设计（R-302 自检）

「一次松手」正是 R-302 预验证的三母题之一（一合扇、一盏灯的熄灭、一次松手）。因果链：天机不可私授 → 手稿呈朝廷 → 子孙不得复学 → 松手=关门。低强度、强因果：✓。灯花轻爆与 EP1 爆亮构成系列书挡——同一声灯花，开头是命运翻页，结尾是故事合上。

## 铁律自检

一个瞬间（献书松手）✓｜一个动作（递交松手）✓｜一种情绪（释然）✓｜清晰人物两位（≤3）✓｜单空间（卧房）✓｜一次视觉转折（松手+灯花）✓

## 系列对仗（终章）

EP1 决绝（封存官文书，秋雨夜灯）→ EP6 释然（交出毕生天书，春雨夜灯）。同一盏灯、同一种雨、同一个「卷」的手势——开头卷起的是前半生，结尾松开的是一生的所知。六集情绪链合拢：决绝→慨然→神定→孤直→忧谗→释然。
