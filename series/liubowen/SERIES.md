## 系列宪法（每集 prompt 复用）

- **跨集身份锁**：系列基准像 `character_ref.jpg`（EP01 终帧 f15 裁切）自 EP02 起随提交上传（upload_file → asset-ids），面容一律以参考图为准；年龄递进 48→50→53→58→61→65 岁，鬓发逐集增白；每集身份锁前置并在简报中重复两次（Rule-503）。EP01 教训已固化：长髯长度白度全程不变、全程站立不坐、结尾光线方向写死。
- **贯穿道具**：一卷星图——EP2 卷起带走，EP6 以《天文书》交出呼应；EP1 以案角白纸收尾（一切从归山开始）。
- **光线**：单一暖光源（R-504），每集换载体：EP1 油灯 / EP2 烛与晨光 / EP3 水战火光（系列唯一反例）/ EP4 堂上烛 / EP5 棋室灯 / EP6 病榻油灯。
- **签名帧**（Rule-501，每集一帧可命名）：EP1 封匣听雨 / EP2 晨光迎门（原定星图最后一眼，成片升级）/ EP3 水柱回眸 / EP4 落笔烛晃 / EP5 黑子落枰 / EP6 松手灯花。
- **声音**（2026-09-02 修订）：简报**不再写「无声」**——强调无声会抑制模型生成环境音效；改为明确要求环境音（更漏、炭盆、风、落子等 R-305 暗示），并注明「不要旁白与对白」。EP05 起生效，首验成功（成片含真实环境音轨）。
- **禁入清单**：烧饼歌、斩龙脉等 C 级传说（系列可信度红线）；画面可辨认文字与印文（R-402，告身/文书一律虚化处理）。
- **史实纪律**：每集引文以《明史·刘基传》为主锚，research.md 按 A/B/C 置信标注；B 级以下不得进入画面因果链。
