# EP01 弃元归山 · 15秒脚本

## 节奏诊断（R-105 八字段）

| 字段 | 值 |
|---|---|
| 类型能量 | 安静观察 → 情绪领悟（沉降型） |
| 观众感受速度 | 极缓；唯一加速与最亮一瞬在合匣灯花爆响 |
| 目标总时长 | 15 秒 |
| 平均 Beat 时长 | 3.75s |
| 最快 Beat | 3s（案面特写） |
| 最慢 Beat | 4.5s（开场全景与结尾定格） |
| 必需停顿 | 合匣后满室一静半拍；抬头前一次呼吸停顿 |
| 收尾停留时长 | ≥2s |

## 故事（一句话）

元末 1358 年秋夜，青田山中书斋，四十八岁的刘伯温把送达的授官告身缓缓卷起、封进旧木匣——匣盖合拢的一瞬灯花爆响；他抬头望向窗外雨夜远山，眼神由郁结转为澄定。

## 脚本（3 个镜头组 · 4 Beats · 一次转折）

**镜头组一｜全景（0–4.5s）**
秋夜书斋，只有案头一盏油灯亮着。他背对竹纸窗、双手按案，俯视案上摊开的那卷绢黄文书（朱红大印沉在灯影里）。雨点打窗，纸面微微震颤。人不动——满室只有雨声和灯。

**镜头组二｜特写 + 中近景（4.5–10.5s）——主动作段**
案面特写：指尖入画，缓缓把告身卷拢，朱红大印随卷动一点点沉入纸影深处。切中近景：他把卷好的告身平放进案头旧木匣，双手合上匣盖——**转折**：匣盖合拢的一瞬，灯花「啪」地爆亮一下（全片最亮），随即光回落；窗纸被一阵山风掀起一角又落回。满室一静半拍。

**镜头组三｜中近景推近（10.5–15s）——收束段**
镜头从他的侧脸缓缓推近。他缓缓抬头，目光穿过窗格投向窗外雨夜远山，眼神由郁结转为澄定，肩线松下来。暖光切过半张脸；右前景案角一叠空白纸与笔砚微微虚化。最后两秒构图完全静止，hold 到结束。

## 声音暗示（R-305）

秋雨打窗（贯穿，细密恒定）→ 卷纸的窸窣（特写段）→ **匣盖合拢的一声闷响 + 灯花爆响**（全片唯一重音，剪辑点所在）→ 山风掠过、雨声忽然显出来的静 → 结尾只有雨。

## 转折设计（R-302 自检）

用一个低强度、强因果的动作切断高速信息流：**合匣**。因果链——任命即羞辱（功被抑、授闲职）→ 封存告身 = 与元廷诀别。转折不剧烈，因果必须成立：✓。前半生被装进匣里，灯花爆响是命运翻页的声音。

## 铁律自检

一个瞬间（告身送达之夜）✓｜一个动作（封匣）✓｜一种情绪（决绝的静）✓｜单主角（全片仅一人）✓｜单空间（书斋）✓｜一次视觉转折（灯花爆）✓
