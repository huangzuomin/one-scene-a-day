# EP04 祭坛斩李彬 · 15秒脚本

## 节奏诊断（R-105 八字段）

| 字段 | 值 |
|---|---|
| 类型能量 | 安静观察 → 孤直决断（沉降型） |
| 观众感受速度 | 极缓；唯一光变在笔落一瞬（由明转暗） |
| 目标总时长 | 15 秒 |
| 平均 Beat 时长 | 3.75s |
| 最快 Beat | 3s（推信取笔） |
| 最慢 Beat | 4.5s（开场全景） |
| 必需停顿 | 落笔前一次呼吸停顿；烛暗之后满室一静 |
| 收尾停留时长 | ≥2s |

## 故事（一句话）

大旱之夜，御史台值房——案上一边是权相的求情书信，一边是待勾的罪案。他把书信推到案角，提起朱笔勾决；笔落一瞬干风入窗、烛火骤暗，他搁笔抬眼，望向窗外无雨的夜空。

## 脚本（3 个镜头组 · 4 Beats · 一次转折）

**镜头组一｜全景（0–4.5s）**
大旱之夜的值房，只有案头一支烛。厚案上公文成堆，居中是一份待勾的罪案，旁边压着一封已拆阅的求情书信。他立于案后，目光在信与案之间移动——权与法，都在案上。

**镜头组二｜特写（4–7s）——推开请托**
案面特写：他的手入画，把那封求情书信缓缓推到案角，推出画面——请托出局。随后指尖提起案上的朱笔。

**镜头组三｜特写（7–10.5s）——落笔·转折**
朱笔悬在罪案上方，一次呼吸的停顿——笔锋落下，划过纸面，只留下一道朱红的勾。就在笔落的一瞬，干风从窗缝侵入，烛火骤然压低，室内由明转暗，墙上烛影晃大。满室一静。

**镜头组四｜中近景（10.5–15s）——搁笔抬眼**
他把朱笔搁在砚边，缓缓抬眼，望向窗外无雨的夜空。压暗的烛光照着他半张脸，神情孤直平静。最后两秒构图完全静止，hold 到结束。

## 声音暗示（R-305）

干风拍窗、更漏、远处隐约的祈雨钟磬 → 纸与案面的摩擦声 → 笔锋划纸的涩响 → **烛火压低时的一声轻响 + 风声骤起**（转折剪辑点）→ 更漏声重新显出来，静。

## 转折设计（R-302 自检）

低强度强因果：推信（拒绝请托）→ 落笔（驰奏勾决的压缩转译）。转折不靠动作剧烈，靠**光的方向**——系列光效第四变：EP1 爆亮（命运翻页）、EP2 涌入（世界打开）、EP3 一闪（生死一瞬）、EP4 骤暗（判决的重量落下来）。骤暗与「方祈雨」的天意压抑同构：他斩李彬以应天变，天却仍未雨。

## 铁律自检

一个瞬间（落笔勾决）✓｜一个动作（推信落笔）✓｜一种情绪（孤直）✓｜单主角（仅一人）✓｜单空间（值房）✓｜一次视觉转折（烛暗）✓

## 系列对仗

EP1 决绝（封存）→ EP2 慨然（开启）→ EP3 神定（先见）→ EP4 孤直（不避）。本集与 EP1 同为「与权力诀别」的夜戏：EP1 封存的是旧朝的官，EP4 勾决的是新朝的人情。
